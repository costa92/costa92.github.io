复现各篇实验

第 3 篇起，每篇的实验都放在示例仓库 costa92/deepseek-harness-demo 的一个子目录里，固定到提交 ad4082d（第 3 篇另见正文）。文中源码行号对应 DeepSeek Harness commit ddefc45fbc，后续版本可能变化。

前提是 dsh 仓库已 pnpm install 并完成构建（各包导出指向构建后的 lib/）。然后在 dsh 仓库根目录取出示例，<demo> 换成各篇「本文的验证范围」里给出的目录名：

mkdir -p scratch-plugin
git clone https://github.com/costa92/deepseek-harness-demo.git scratch-plugin/deepseek-harness-demo
git -C scratch-plugin/deepseek-harness-demo checkout --detach ad4082d
cp -R scratch-plugin/deepseek-harness-demo/<demo> scratch-plugin/<demo>

之后运行各篇给出的 node --import tsx/esm ... 命令。已经克隆过示例仓库时，跳过 mkdir 和 git clone，先执行 git -C scratch-plugin/deepseek-harness-demo fetch，再从 checkout 开始；scratch-plugin/<demo> 须尚不存在，否则 cp -R 会复制成嵌套目录。

脚本每一步都带断言，行为与文中不符时以非零退出码结束。各篇末尾的运行截图来自本机终端，终端字体带连字，个别符号与正文代码块字形略有出入。
