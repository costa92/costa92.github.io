一次性任务与定时任务

Deployment 维持持续运行的副本；Job 则负责让任务成功完成。CronJob 按时间表创建 Job，适合定时清理、报表等任务。请先确认当前命名空间为 k8s-lab。

保存为 job.yaml：

apiVersion: batch/v1
kind: Job
metadata:
  name: demo-once
spec:
  backoffLimit: 2
  template:
    spec:
      restartPolicy: Never
      containers:
        - name: task
          image: busybox:1.36
          command: ["sh", "-c", "echo job finished"]
kubectl apply -f job.yaml
kubectl wait --for=condition=complete job/demo-once --timeout=120s
kubectl logs job/demo-once
kubectl describe job demo-once

若失败，查看 Job 创建的 Pod 及其日志。Job 可能重试，所以任务应尽量能安全重复执行。

定时执行

保存为 cronjob.yaml：

apiVersion: batch/v1
kind: CronJob
metadata:
  name: demo-scheduled
spec:
  schedule: "*/5 * * * *"
  timeZone: "Etc/UTC"
  concurrencyPolicy: Forbid
  successfulJobsHistoryLimit: 1
  failedJobsHistoryLimit: 1
  jobTemplate:
    spec:
      template:
        spec:
          restartPolicy: Never
          containers:
            - name: task
              image: busybox:1.36
              command: ["sh", "-c", "date; echo scheduled"]
kubectl apply -f cronjob.yaml
kubectl get cronjob,jobs
kubectl delete -f cronjob.yaml
kubectl delete -f job.yaml

Forbid 避免前一次任务尚未结束时并发启动，但不保证每次计划执行恰好一次。需要严格的一次性业务语义时，要在应用层处理重复与漏执行。

参考：Job、CronJob。
