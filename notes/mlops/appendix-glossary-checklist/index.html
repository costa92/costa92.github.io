核心术语

术语含义
Artifact（制品）训练生成的模型、报告、图表等不可变产出。本系列的用词约定：每篇首次出现写「制品（artifact）」，其后统一用「制品」；只有在指代具体 API 或字段名时保留英文原文，如 log_artifacts、artifact_path、Argo 的 outputs.artifacts
Run一次具体实验或训练执行
Registry管理候选模型版本、证据和生命周期的系统
Data drift线上输入分布相对基线变化
Concept drift输入与正确输出之间的关系变化
Training-serving skew训练和推理的特征计算或数据语义不一致
Point-in-time join只使用预测时刻之前可获得的数据关联特征
Canary小比例真实流量验证新版本
Shadow复制真实请求验证新版本但不影响用户结果
SLI/SLO服务指标与目标，例如 p95 延迟及其目标值
InferenceServiceKServe 用于声明模型服务的 Kubernetes 资源

机器学习术语（面向无 ML 背景的读者）

按本系列首次出现的顺序排列，括号里是展开讲它的篇号。

术语含义
特征（feature）模型实际吃进去的数字化输入。文本要先变成向量才能进模型（01）
标签（label）希望模型预测的答案，本系列是 billing / technical_support / account 三选一（01）
TF-IDF把文本变成向量的方法：词频 × 逆文档频率。IDF 从训练语料统计而来，属于模型的一部分，这是训练—推理一致性的根源（01、03、16）
n-gram把文本切成连续的 n 个单位。本系列用字符级 2–4 gram，不依赖中文分词器（03）
过拟合（overfitting）模型把训练集的噪声也背了下来。表现是训练集分数漂亮、没见过的数据上明显变差——离线好、线上差通常就是它（01）
欠拟合（underfitting）模型连训练数据里的基本模式都没学到。表现是训练集和测试集两边都差，不存在”离线好线上差”这回事（01）
Precision / Recall / F1查准率 / 查全率 / 两者的调和平均。漏判和误判的代价不同时必须分开看（01）
macro F1每个类别的 F1 取算术平均，不按样本量加权，所以小类别退化藏不住。本系列的主指标（03）
weighted F1按各类别样本量加权的 F1，更贴近整体体验，但会掩盖小类别问题。与 macro 一起看才有意义（07）
分层抽样（stratify）划分训练/测试集时保持各类别比例一致，避免小类别被整个划走（03）
超参数（hyperparameter）训练前人为设定、训练中不变的参数，如 ngram_range、C。区别于模型自己学出来的权重（03、07）
数据泄漏（data leakage）训练时用到了预测时刻拿不到的信息，导致离线指标虚高、上线打回原形。最常见的两种形态是重复样本跨越训练/测试集，和用未来数据算特征（13、16）
测试集污染 / data snooping人在选参、选模型的过程中反复消费了测试集，导致最终报出的分数偏乐观。和数据泄漏后果相同、机制不同：泄漏发生在特征里，污染发生在决策流程里。防法是交叉验证选参、测试集只评一次（01、07）
交叉验证（cross-validation）把训练集轮流切成 K 份、每份轮流当验证集，取平均分作为选参依据。数据量不足以单独切验证集时的标准做法，同时给出分数的波动范围（07）
置信度校准（calibration）模型输出的 0.9 是否真的对应 90% 正确率。未经校准的 confidence 只能用来排序，不能当概率用（04、20）
PSI总体稳定性指数，衡量两个分布的差异程度。常用判读：< 0.1 稳定、0.1–0.25 需观察、> 0.25 需调查（17）
Point-in-time correctness见上表的 Point-in-time join。做不到它，特征里就会混进标签的下游产物（16）
Feature Store把特征当作独立资产管理的系统。多数单模型项目不需要它——本系列第 16 篇给了判据（16）
alias（MLflow）指向某个模型版本的可移动指针，如 production。MLflow 3 用它取代了旧的 Stage（15）

上线前检查

数据与模型

  • 数据版本、Schema 和验证报告已保存；
  • 没有明显泄漏，时间切分符合业务；
  • 指标按关键切片评估；
  • 模型关联 Git SHA、镜像 digest、Run ID；
  • artifact 已签名或校验摘要；
  • 兼容性和反序列化风险已评估。

服务与发布

  • API Schema、错误码和大小限制明确；
  • liveness、readiness、startup 语义正确；
  • 压测覆盖目标并发与模型启动；
  • 镜像非 root、只读、依赖扫描并生成 SBOM；
  • Canary/Shadow 策略及自动回滚条件明确；
  • 旧应用—模型—特征组合可恢复。

平台与安全

  • IAM、ServiceAccount、S3 权限最小化；
  • TLS、认证、限流和 NetworkPolicy 已配置；
  • Secret 不存在代码、镜像或明文清单中；
  • PDB、资源 requests/limits 和多可用区策略合理；
  • 备份恢复与模型仓库故障完成演练。

运营

  • Metrics、Logs、Traces 含模型版本和 request ID；
  • 系统 SLO 与模型质量 SLO 分开定义；
  • 预测事件能与延迟到达的真实标签关联；
  • 漂移、质量下降和重训练各有处理人；
  • Runbook、值班告警和成本预算已确认。
