第 1 / 25 节 · 系列导读

一套面向 DevOps、SRE 和云原生工程师的原创中文 MLOps 系列。系列使用“用户意图分类服务”作为连续案例，从机器学习基础开始，覆盖数据、训练、发布、KServe、监控反馈和生产治理闭环。

配套代码：costa92/intent-mlops（MIT 许可），训练、服务、部署清单和监控规则都可以直接 clone 运行；正文里的 example/... 路径对应仓库中的同名文件。

你会完成什么

训练数据
  ↓ DVC + Git + S3
Scikit-learn 训练
  ↓ MLflow Tracking / Registry
模型制品
  ↓ Flask + Docker
在线推理 API
  ↓
本地 → AWS VM → AWS EKS → KServe

阅读完后，你应该能解释并实践：

  • ML 系统与普通应用在生产风险上的差异；
  • CI/CD/CT 如何形成数据—训练—部署—反馈闭环；
  • 如何训练、评估、保存和重新加载模型；
  • 如何版本化数据并追踪实验；
  • 如何设计模型 API 和容器；
  • VM、Kubernetes 与 KServe 分别解决什么问题；
  • 哪些能力仍需要模型注册、GitOps、监控和治理系统补充。

推荐阅读路径

  • 完整入门：按 01—20 顺序阅读；
  • 可部署最短路径：03 → 04 → 08 → 09 → 10 → 11（读完能把模型跑上 Kubernetes）；
  • 关注可复现性：02 → 03 → 05 → 06 → 07；
  • Kubernetes 平台工程：04 → 08 → 10 → 11 → 12（12 讲入口网关与服务网格，单体推理服务可只看网关那半篇）；
  • 完整生产闭环：13 → 14 → 15 → 16 → 17 → 18（16 讲特征一致性，特征不来自数据库或实时流时可跳过）；
  • 上线之后的长期运营：19 → 20（SLO 与错误预算、安全边界与成本治理）。

示例的边界

example/ 可以在安装依赖后本地训练、测试和启动 API，但仍是教学工程。真实系统需要结合组织要求接入正式 Registry、云身份、GitOps、指标后端、隐私治理和灾难恢复。
