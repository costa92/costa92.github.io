训练阶段

分层切分报错

原因通常是某个标签样本太少。先运行 make validate 查看类别数量，不要通过关闭 stratify 掩盖数据问题。

离线指标突然提高

优先检查重复样本、同一会话跨集合、未来数据泄漏和测试集是否参与调参，而不是马上宣布模型改进。

本地可加载，容器无法加载

比较 Python、scikit-learn、joblib 版本和 artifact checksum。模型序列化并不保证跨任意版本兼容。

API 与容器

/healthz 正常但 /readyz 503

进程存活但模型未加载。检查 MODEL_PATH、文件权限、工作目录、checksum 和加载异常日志。

Gunicorn worker 不断重启

检查内存限制和模型在每个 worker 中的副本。不要盲目增加 worker；先测单进程内存和安全并发。

Docker 只读文件系统失败

应用正在写工作目录。将临时文件写入 /tmp 并配置 tmpfs，模型和配置保持只读。

MLflow 与 DVC

MLflow 有 run 但 artifact 丢失

确认 Tracking Server 的 artifact URI、Pod IAM、S3 prefix 和数据库记录是否一致。数据库备份不能替代 S3 备份。

dvc pull 返回权限错误

检查 remote URL、AWS region、凭证来源和 S3/KMS 权限。CI 优先使用 OIDC，EKS 使用 Pod Identity/IRSA。

Kubernetes 与 KServe

Pod Running 但没有流量

依次检查 readiness、Service selector、Endpoints、IngressClass、Traefik route 和外部 Load Balancer。

HPA 不扩容

检查 Metrics Server、自定义指标适配器、requests 是否设置，以及指标是否真的超过 target。

KServe InferenceService Not Ready

查看 InferenceService condition、revision/pod 事件和 storage initializer 日志。常见原因是模型格式不兼容、S3 权限、runtime 不存在或资源不足。

新版本 Canary 指标恶化

先冻结放量并回滚 GitOps 提交，再保留新旧版本的预测事件用于对比。不要原地覆盖模型 URI，否则无法复盘。

监控

Prometheus 没有抓到指标

检查 Service label 是否匹配 ServiceMonitor selector、端口名称是否为 http、Prometheus namespaceSelector 和 RBAC。

漂移告警频繁误报

检查样本量、季节性、基线选择和切片。漂移是调查信号，不应直接等同模型质量下降。
